# 制御工学学習シミュレータ

制御工学の基本原理を直感的に体感・学習できるインタラクティブWebアプリケーションです。  
画面上部のタブで、**「🔄 振子モータ制御系」** と **「⏹️ マス・バネ・ダンパー系」** の2大古典制御モデルをワンクリックで切り替えてシミュレーションできます。

手動操作（マウスドラッグ・指スワイプ・キーボード）と **Autoモード（PID位置制御）** を備え、時系列応答グラフ（目標値・現在値・制御入力）や相平面プロット（状態空間軌跡）により、制御工学の重要概念（過渡応答、整定時間、減衰比、定常偏差の積分消去など）を深く理解できます。

## 🚀 起動方法

### 方法 1: `起動.bat` をダブルクリック（推奨）
プロジェクトフォルダ内の `起動.bat`（または `run.bat`）をダブルクリックすると、ローカルサーバーが起動しブラウザが自動的に開きます。
同時に、コンソール画面に「同じWi-Fi内のスマホからアクセスするためのURL」も表示されます。

### 方法 2: `standalone.html` をダブルクリック
サーバーの起動すら不要です。`standalone.html` をお好みのブラウザ（Google Chrome, Microsoft Edge など）にドラッグ＆ドロップまたはダブルクリックするだけで即座にプレイできます。

## 🕹️ 2つの制御系モデル

### 1. 🔄 振子モータ制御系 (Pendulum Motor System)
- **概要**: 360°回転可能な振子の支点にモータを取り付け、トルク $\tau$ を印加して目標角度 $\theta_{target}$ へ静止させるシステム。
- **運動方程式**:
  $$m l^2 \ddot{\theta} + c \dot{\theta} + m g l \sin\theta = \tau$$
- **学習の着眼点**:
  - **非線形性**: $\sin\theta$ の項があるため、角度によって重力トルクが変化。
  - **倒立振子 (180°)**: 不安定平衡点。手動でピタッと静止させるのは極めて困難で、Auto PID制御の強力さが実感できます。
  - **スイングアップ**: モータトルクが重力トルクより小さい場合（$\tau_{max} < mgl$）、振り子を前後に揺らしてエネルギーを蓄積する助走が必要。

### 2. ⏹️ マス・バネ・ダンパー系 (Mass-Spring-Damper System)
- **概要**: 壁に固定されたばね $K$ とダンパー $D$ が床面の台車（質量 $m$）に接続され、入力外力 $F$ を加えて目標位置 $x_{target}$ に位置決めするシステム。
- **運動方程式**:
  $$m \ddot{x} + D \dot{x} + K x = F$$
  $$\ddot{x} = \frac{F - D \dot{x} - K x}{m}$$
- **2次遅れ系の動特性**:
  - **固有角周波数**: $\omega_n = \sqrt{K / m}$ [rad/s]
  - **減衰比**: $\zeta = \frac{D}{2\sqrt{m K}}$
    - $\zeta < 1$: **不足減衰**（振動しながら徐々に静止）
    - $\zeta = 1$: **臨界減衰**（行き過ぎなく最速で静止）
    - $\zeta > 1$: **過減衰**（粘性が強すぎてゆっくり収束）
    - $\zeta = 0$: **非減衰**（永久に等振幅で単振動）
- **制御工学の最大着眼点（定常偏差と積分項 $K_i$）**:
  - バネの復元力 $-Kx$ が働くため、**P制御（$F = K_p(x_{target} - x)$）だけでは目標位置に届かない定常偏差（オフセット）が必ず残ります**：
    $$x(\infty) = \frac{K_p}{K + K_p} x_{target}$$
  - ここに **I制御（積分ゲイン $K_i$）** を導入することで、時間の経過に伴って偏差が積分され、バネ抗力と完全に釣り合う力が蓄積されて **定常偏差がゼロ消去** される劇的な様子を体験できます！

## 🎮 操作方法（無段階・アナログ対応）

本アプリは、繊細なバランス制御ができるよう**マウスドラッグ・指スワイプによる無段階アナログ入力**に対応しています。

| 操作方法 | 動作内容 |
| :--- | :--- |
| **スライダーのドラッグ / スワイプ** | バーの中央(0)から操作。位置に応じて出力（トルク $\tau$ または外力 $F$）が無段階に連続変化します。 |
| **マウスホイール** | スライダーやシミュレーション画面上でホイールを回すと、出力を細かく微増減できます。 |
| **`←` / `→` キー (または `A` / `D`)** | 押している時間に応じてスムーズに加速（短押しで微小出力、長押しで最大出力）。 |
| **微動ボタン (`◀ 微動`, `微動 ▶`)** | クリックごとに出力を微調整します。 |
| **`Space` キー / 「ゼロ復帰」ボタン** | 出力を即座に 0（ニュートラル）にします。 |
| **おもり・マスの直接ドラッグ** | 振子のおもりやマスを直接マウス/指で掴んで引っ張り、離して自由振動や外乱応答を実験できます。 |
| **`R` キー / 「リセット」ボタン** | 状態を初期位置（静止）にリセットします。 |

### 🕹️ ドライブモード（Manual vs Auto PID制御）
- **🎮 Manual (手動操作)**:
  - 人間のスライダー操作・スワイプ・キーボード入力によって制御入力を自由にコントロールします。
- **🤖 Auto (PID自動位置制御)**:
  - PID制御アルゴリズムが、目標値との偏差をリアルタイムに計算して自動制御します。
  - **外乱応答実験**: Autoモード中に振子やマスを掴んで引っ張ってみてください。PIDコントローラが力強く目標位置へ引き戻そうとする様子が体感できます。

## 🎛️ PID制御パラメータ（Autoモード）

PIDゲインは設定パネルからリアルタイムに変更可能です：

- **振子系**: $\tau(t) = K_p e(t) + K_i \int e(t) dt - K_d \omega(t)$
- **マスバネダンパー系**: $F(t) = K_p e(t) + K_i \int e(t) dt - K_d v(t)$

- **$K_p$ (比例ゲイン)**: 偏差の大きさに比例して目標方向へ引き戻す復元力。
- **$K_i$ (積分ゲイン)**: 重力やバネ抗力によって残る**定常偏差（オフセット）をゼロに消去**します。
- **$K_d$ (微分ゲイン)**: 速度を抑制する**制動ブレーキ（ダンピング）**。オーバーシュートや振動をピタッと抑え込みます。

## 📊 制御工学ダッシュボード（リアルタイム描画）

1. **時系列応答 (Time History)**:
   - 状態量（角度 $\theta$ / 変位 $x$）（シアン）
   - 目標値（$\theta_{ref}$ / $x_{ref}$）（黄色破線）
   - 制御入力（トルク $\tau$ / 外力 $F$）（緑）
   - オーバーシュート（行き過ぎ量）や整定時間、定常偏差を観察できます。
2. **相平面プロット (Phase Plane)**:
   - 振子系: 横軸に角度 $\theta$、縦軸に角速度 $\omega$
   - マスバネダンパー系: 横軸に変位 $x$、縦軸に速度 $v$
   - 平衡点へ向かう渦巻き軌跡（減衰振動）や収束挙動が直感的に視覚化されます。
