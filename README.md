# 制御工学学習用 振子モータ制御シミュレータ

長さ $l$ の棒の先に質量 $m$ のおもりが付いた振子と、支点のモータートルク入力を備えた制御工学学習用Webアプリケーションです。  
人間のキーボード操作（←/→矢印キー）でモータートルクを直接操作し、360°回転可能な振子の角度を目標位置に安定化させるゲーム風シミュレーションを通じて、制御の難しさや物理ダイナミクスを直感的に学ぶことができます。

---

## 🚀 起動方法

### 方法 1: `起動.bat` をダブルクリック（推奨）
プロジェクトフォルダ内の `起動.bat`（または `run.bat`）をダブルクリックすると、ローカルサーバーが起動しブラウザが自動的に開きます。
同時に、コンソール画面に「同じWi-Fi内のスマホからアクセスするためのURL」も表示されます。

### 方法 2: `standalone.html` をダブルクリック
サーバーの起動すら不要です。`standalone.html` をお好みのブラウザ（Google Chrome, Microsoft Edge など）にドラッグ＆ドロップまたはダブルクリックするだけで即座にプレイできます。

## 👆 スマホでの操作
- **指でおもりを直接ドラッグ**: 画面上の振子のおもりを指で掴んで好きな角度まで引っ張り、離してシミュレーションを開始できます。
- **大型トルクボタン**: 画面下の「◀ 左回転」「右回転 ▶」ボタンを親指で押してトルク操作が可能です。
- **タブ切り替え**: スマホ画面上部の「🎮 振子操作」「📈 応答グラフ」「⚙️ 設定」タブで画面を切り替えて操作できます。

---

## 🎮 操作方法

| キー / 操作 | 動作 |
| :--- | :--- |
| **`←` または `A`** | 反時計回り（CCW: 正方向）にモータートルクを発生 |
| **`→` または `D`** | 時計回り（CW: 負方向）にモータートルクを発生 |
| **`Space`** | トルクを即座にゼロ（ニュートラル）にする |
| **`R`** | 振子の状態を初期位置（最下点・静止）にリセット |
| **`⏸ 一時停止` ボタン** | シミュレーションを一時停止 / 再開 |

### 操作モードの切替
- **押しっぱなしモード (Momentary)**: キーを押している間だけトルクが発生し、離すと0に戻ります（ゲームコントローラー風）。
- **スロットルモード (Throttle)**: 矢印キーを押すごとにトルク指令値が増減し、出力を維持します（アクセルレバー風）。

## 🎯 ゲーム＆学習要素

1. **目標角度への安定化チャレンジ**:
   - 画面上に破線で表示されている「目標姿勢（ゴースト振子）」に振子を合わせ、静止させてください。
   - 角度偏差が小さく、角速度がほぼゼロの状態で **2秒間キープ** すると **「★ STABILIZED! ★」** と表示されクリアとなります！
   - 特に初期設定の **180°（倒立状態）** は不安定平衡点のため、手動でピタッと止めるのは至難の業です。自動制御（PIDや状態フィードバック）の重要性を肌で実感できます。

2. **学習プリセット**:
   - **標準設定 (倒立180°)**: 倒立振子を手動で安定化させる王道チャレンジ。
   - **水平保持 (90°)**: 重力トルク（$mgl$）と釣り合うトルクを維持する課題。
   - **スイングアップ必須**: 最大トルク $\tau_{max} < mgl$ に設定されており、一発で倒立まで持ち上がりません。ブランコのように左右にタイミングよくトルクを加えてエネルギーを蓄積する「スイングアップ制御」の学習ができます。
   - **短尺・俊敏振子**: 固有周期が短く、素早い反応が必要。
   - **長尺・高慣性**: 慣性モーメントが大きく、一度勢いがつくと止めるのが困難。
   - **無重力 (宇宙)**: 重力復元力のない純粋な回転慣性系の制御。

3. **制御工学ダッシュボード（リアルタイム描画）**:
   - **時系列応答 (Time History)**:
     - 角度 $\theta(t)$（シアン）
     - 目標角度 $\theta_{ref}$（黄色破線）
     - トルク $\tau(t)$（緑）
     - オーバーシュート（行き過ぎ量）や整定時間、定常偏差を観察できます。
   - **相平面プロット (Phase Plane: $\theta$ vs $\dot{\theta}$)**:
     - 横軸に角度、縦軸に角速度をとった状態空間の軌跡。
     - 平衡点へ向かう渦巻き軌跡（減衰振動）やリミットサイクルが視覚化されます。

## 📐 物理モデルと運動方程式

- **棒の長さ**: $l$ [m]
- **先端質量**: $m$ [kg]
- **慣性モーメント**: $J = m l^2$ [kg·m²]
- **粘性減衰係数**: $c$ [N·m·s/rad]
- **モータートルク**: $\tau$ [N·m]（$|\tau| \le \tau_{max}$）
- **重力加速度**: $g$ [m/s²]

### 運動方程式
$$J \ddot{\theta} + c \dot{\theta} + m g l \sin\theta = \tau$$

角加速度:
$$\ddot{\theta} = \frac{\tau - c \dot{\theta} - m g l \sin\theta}{m l^2}$$

数値積分には **4次ルンゲ＝クッタ法 (RK4)** を採用し、サブステップ積分により激しい回転やトルク急変時でも高い計算精度と安定性を維持しています。
