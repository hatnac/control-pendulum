周波数応答とボード線図の物理的意味 G(jω) = Y(jω) / U(jω)

線形システムに正弦波入力 $u(t) = A_{in} \sin(\omega t)$ を加えると、定常状態では出力も同じ周波数の正弦波 $y(t) = A_{out} \sin(\omega t + \phi)$ になります。

① ゲイン比 (振幅比) [dB]
20 log₁₀(A_out / A_in)
  • 低周波 (ω → 0): 静的変位に一致 (マスバネ系なら 1/K)。
  • 共振点 (ω ≈ ωn): ばねの復元力と質量慣性が打ち消し合い、ダンパー粘性のみで抑制されるため振幅が大きく跳ね上がります（共振ピーク）。
  • 高周波 (ω → ∞): 質量慣性が抵抗となり、出力振幅が急激に低下 (傾き -40 dB/decade)。
② 位相差 (時間遅れ) [deg]
φ = -ω · Δt [rad]
  • 低周波 (ω → 0): 入力と同じタイミングで動く（φ ≈ 0°、同位相）。
  • 共振点 (ω = ωn): ちょうど 1/4 周期遅れる（φ = -90°）。速度と外力が同位相となりエネルギーが最も注入されます。
  • 高周波 (ω → ∞): 入力と完全に真逆の動きになる（φ → -180° 逆位相）！
